# Light-and-Nature-Foundation

This is the official website for the **Light and Nature Foundation (LNF)** — a nonprofit organization rooted in community development, humanitarian action, and environmental stewardship across Kenya and Africa.

Built with HTML5, Tailwind CSS, and responsive design principles, the website highlights our mission, projects, leadership, and donation channels to support meaningful change.

## Features
- **Responsive Design**: Mobile-first navigation and layout using Tailwind CSS.
- **Projects Showcase**: Highlighting environmental and community initiatives.
- **Gallery**: A curated look at our on-the-ground impact.
- **Leadership**: Introductions to the visionary team guiding the foundation.

## Local Setup
1. Clone the repository: `git clone https://github.com/Sege-Peter/Light-and-Nature-Foundation.git`
2. Open `index.html` in any modern web browser to view the site locally. No build step or local server is required.

## Technologies Used
- HTML5
- Tailwind CSS (via CDN)
- Animate.css (via CDN)
- FontAwesome (via CDN)
